# Zafar Riza | Portfolio

Personal portfolio website for Zafar Riza: scientist, founder of ZR PRODUCTIONS, and published author.

It is a single self-contained `index.html` (photo and book covers are embedded), so there is no build step.

## Run locally
Open `index.html` in any browser.

## Deploy with GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/` within a minute or two.
